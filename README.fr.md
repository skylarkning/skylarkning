# À propos de moi

**Ingénieur performance chez Mozilla Firefox**

Hi, je suis Chutian (Sky) Ning, ingénieur performance pour [Firefox](https://www.firefox.com/) chez [Mozilla](https://www.mozilla.org/) et passionné d’aviation de longue date, avec plus de 15 ans d’expérience en simulation de vol.

Je travaille sur les performances de Firefox, notamment :

- L’amélioration de Background Hang Reporter (BHR), désormais appelé [HangTime](https://skylarkning.github.io/HangTime/#/top-hangs)
- L’optimisation de [Speedometer 3](https://browserbench.org/Speedometer3.0/)
- L’optimisation des performances réseau de Firefox, notamment les Speculation Rules
- Les performances de Firefox pour Android (Fenix)
- Tout autre sujet dans Firefox qui retient mon attention

En parallèle de mon travail sur Firefox, je développe des logiciels de simulation de vol tels que **TaxiNow** et **SkyCharts**, et je participe à la recherche et au développement de matériel de simulation de vol avec **[WINGFLEX Simulator](https://wingflex.com/)**.

### Sélection de projets

**[HangTime](https://github.com/skylarkning/HangTime)**  
Un tableau de bord interactif pour explorer les données de blocage de Firefox, analyser les piles d’appels et partager les résultats.

**[Speculation Rules Testbench](https://github.com/skylarkning/Speculation-Rules-Testbench)**  
Un banc d’essai et une extension des outils de développement pour étudier le chargement spéculatif dans Firefox. [Essayer le laboratoire →](https://skylarkning.github.io/Speculation-Rules-Testbench/)

**[TaxiNow](https://github.com/skylarkning/TaxiNow-Release)**  
Une carte de navigation au sol pour Microsoft Flight Simulator 2020/2024, avec positionnement de l’avion en temps réel et informations détaillées sur les voies de circulation des aéroports.

**[SkyCharts](https://github.com/skylarkning/SkyCharts)**  
Une application de consultation de cartes aéronautiques hors ligne pour la simulation de vol, avec des cartes interactives d’aéroports, conçue pour les anciens iPad sous iOS 6.

*TaxiNow et SkyCharts sont exclusivement destinés à la simulation de vol.*
