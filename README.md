# About Me · 关于我

**Performance Engineer at Mozilla Firefox · Mozilla Firefox 性能工程师**

Hi, I'm Chutian (Sky) Ning, a Performance Engineer at Mozilla Firefox and a longtime aviation enthusiast with over 15 years of flight simulation experience.

I work on Firefox performance, including:

- Background Hang Reporter (BHR) augmentation
- Speedometer 3 optimization
- Firefox networking performance optimization, including Speculation Rules
- Firefox for Android (Fenix) performance
- Anything else in Firefox that catches my attention

Beyond my work on Firefox, I develop flight simulation software such as **TaxiNow** and **SkyCharts**, and work on flight simulation hardware research and development with **[WINGFLEX Simulator](https://wingflex.com/)**.

Hi，我是 Chutian (Sky) Ning，目前在 Mozilla 担任 Firefox 性能工程师，我也是一名拥有超过15年模拟飞行经验的航空爱好者。

我的工作主要围绕 Firefox 性能展开，包括：

- Background Hang Reporter（BHR）功能增强
- Speedometer 3 性能优化
- Firefox 网络性能优化，包括 Speculation Rules
- Firefox Android（Fenix）性能优化
- Firefox 中任何引起我兴趣的其他问题

除了 Firefox 的工作，我也开发 **TaxiNow**、**SkyCharts** 等模拟飞行软件，并与 **[WINGFLEX Simulator](https://wingflex.com/)** 合作开展模拟飞行硬件研发。

### Selected projects · 精选项目

**[HangTime](https://github.com/skylarkning/HangTime)**  
An interactive dashboard for exploring Firefox hang data, inspecting stacks, and sharing findings.  
Firefox 卡顿数据分析面板，支持交互式浏览、调用栈分析与结果分享。

**[Speculation Rules Testbench](https://github.com/skylarkning/Speculation-Rules-Testbench)**  
A testbench and DevTools extension for investigating speculative loading in Firefox. [Try the lab →](https://skylarkning.github.io/Speculation-Rules-Testbench/)  
用于研究 Firefox Speculative Loading 行为的实验平台与开发者工具扩展。

**[TaxiNow](https://github.com/skylarkning/TaxiNow-Release)**  
A ground-navigation map for Microsoft Flight Simulator 2020/2024, with live aircraft positioning and detailed airport taxiway information.  
面向微软模拟飞行 2020/2024 的机场地面导航工具，提供实时飞机定位与详细滑行道信息。

**[SkyCharts](https://github.com/skylarkning/SkyCharts)**  
An offline flight simulation chart viewer with interactive airport maps, built for legacy iPads running iOS 6.  
为运行 iOS 6 的老款 iPad 打造的离线模拟飞行航图应用，支持交互式机场地图。

*TaxiNow and SkyCharts are for flight simulation only. / TaxiNow 与 SkyCharts 仅用于模拟飞行。*
