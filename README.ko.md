# 소개

**Mozilla Firefox 성능 엔지니어**

Hi, 저는 Chutian (Sky) Ning입니다. [Mozilla](https://www.mozilla.org/)에서 [Firefox](https://www.firefox.com/) 성능 엔지니어로 일하고 있으며, 15년 이상의 비행 시뮬레이션 경험을 가진 오랜 항공 애호가입니다.

Firefox 성능과 관련하여 다음 분야에 참여하고 있습니다.

- Background Hang Reporter(BHR) 기능 강화. 현재는 [HangTime](https://skylarkning.github.io/HangTime/#/top-hangs)이라는 이름을 사용합니다
- [Speedometer 3](https://browserbench.org/Speedometer3.0/) 최적화
- Speculation Rules를 포함한 Firefox 네트워크 성능 최적화
- Android용 Firefox(Fenix) 성능
- 그 밖에 Firefox에서 제 관심을 끄는 다양한 문제

Firefox 업무 외에도 **TaxiNow**, **SkyCharts** 등 비행 시뮬레이션 소프트웨어를 개발하고, **[WINGFLEX Simulator](https://wingflex.com/)**와 함께 비행 시뮬레이션 하드웨어 연구 및 개발에 참여하고 있습니다.

### 비행 시뮬레이션

소프트웨어 개발부터 **[WINGFLEX Simulator](https://wingflex.com/)**와의 하드웨어 연구개발까지, 비행 시뮬레이션 분야에서 진행한 작업 일부를 소개합니다.

- [FSElite 인터뷰](https://www.youtube.com/watch?v=1paetochC4I)
- [WINGFLEX 출시 행사](https://www.youtube.com/watch?v=pYfTzKgviuQ)

### 주요 프로젝트

**[HangTime](https://github.com/skylarkning/HangTime)**  
Firefox 멈춤 데이터를 탐색하고 호출 스택을 분석하며 결과를 공유할 수 있는 대화형 대시보드입니다.

**[Speculation Rules Testbench](https://github.com/skylarkning/Speculation-Rules-Testbench)**  
Firefox의 추측 로딩 동작을 조사하기 위한 테스트 환경과 개발자 도구 확장 기능입니다. [실험 환경 사용해 보기 →](https://skylarkning.github.io/Speculation-Rules-Testbench/)

**[TaxiNow](https://github.com/skylarkning/TaxiNow-Release)**  
Microsoft Flight Simulator 2020/2024용 지상 항법 지도입니다. 실시간 항공기 위치와 상세한 공항 유도로 정보를 제공합니다.

**[SkyCharts](https://github.com/skylarkning/SkyCharts)**  
iOS 6를 사용하는 구형 iPad용 오프라인 비행 시뮬레이션 항공 차트 앱입니다. 대화형 공항 지도도 지원합니다.

*TaxiNow와 SkyCharts는 비행 시뮬레이션 전용입니다.*
