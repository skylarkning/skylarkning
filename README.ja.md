# 自己紹介

**Mozilla Firefox パフォーマンスエンジニア**

Hi、Chutian (Sky) Ning です。[Mozilla](https://www.mozilla.org/) で [Firefox](https://www.firefox.com/) のパフォーマンスエンジニアとして働いています。長年の航空ファンでもあり、フライトシミュレーションの経験は 15 年以上あります。

Firefox のパフォーマンスに関する業務として、主に次の分野に取り組んでいます。

- Background Hang Reporter（BHR）の機能拡張。現在は [HangTime](https://skylarkning.github.io/HangTime/#/top-hangs) という名称です
- [Speedometer 3](https://browserbench.org/Speedometer3.0/) の最適化
- Speculation Rules を含む Firefox のネットワーク性能の最適化
- Android 版 Firefox（Fenix）のパフォーマンス
- その他、Firefox で興味を引かれた課題

Firefox の仕事以外では、**TaxiNow** や **SkyCharts** などのフライトシミュレーション関連ソフトウェアを開発し、**[WINGFLEX Simulator](https://wingflex.com/)** とともにフライトシミュレーション用ハードウェアの研究開発にも取り組んでいます。

### フライトシミュレーション

ソフトウェア開発から **[WINGFLEX Simulator](https://wingflex.com/)** とのハードウェア研究開発まで、フライトシミュレーション分野での活動の一部をご紹介します。

### 主なプロジェクト

**[HangTime](https://github.com/skylarkning/HangTime)**  
Firefox のハングデータを探索し、コールスタックを分析して結果を共有できる、インタラクティブなダッシュボードです。

**[Speculation Rules Testbench](https://github.com/skylarkning/Speculation-Rules-Testbench)**  
Firefox の投機的読み込みを調べるためのテスト環境と開発者ツール拡張機能です。[実験環境を試す →](https://skylarkning.github.io/Speculation-Rules-Testbench/)

**[TaxiNow](https://github.com/skylarkning/TaxiNow-Release)**  
Microsoft Flight Simulator 2020/2024 向けの地上ナビゲーションマップです。リアルタイムの機体位置と空港の詳しい誘導路情報を表示します。

**[SkyCharts](https://github.com/skylarkning/SkyCharts)**  
iOS 6 を搭載した旧型 iPad 向けの、フライトシミュレーション用オフライン航空チャートアプリです。インタラクティブな空港マップにも対応しています。

*TaxiNow と SkyCharts はフライトシミュレーション専用です。*
