# 关于我

**Mozilla Firefox 性能工程师**

Hi，我是 Chutian (Sky) Ning，目前在 [Mozilla](https://www.mozilla.org/) 担任 [Firefox](https://www.firefox.com/) 性能工程师，也是一名拥有超过 15 年模拟飞行经验的航空爱好者。

我的工作主要围绕 Firefox 性能展开，包括：

- Background Hang Reporter（BHR）功能增强，现称为 [HangTime](https://skylarkning.github.io/HangTime/#/top-hangs)
- [Speedometer 3](https://browserbench.org/Speedometer3.0/) 性能优化
- Firefox 网络性能优化，包括 Speculation Rules
- Firefox Android（Fenix）性能优化
- Firefox 中任何引起我兴趣的其他问题

除了 Firefox 的工作，我也开发 **TaxiNow**、**SkyCharts** 等模拟飞行软件，并与 **[WINGFLEX Simulator](https://wingflex.com/)** 合作开展模拟飞行硬件研发。

### 精选项目

**[HangTime](https://github.com/skylarkning/HangTime)**  
Firefox 卡顿数据分析面板，支持交互式浏览、调用栈分析与结果分享。

**[Speculation Rules Testbench](https://github.com/skylarkning/Speculation-Rules-Testbench)**  
用于研究 Firefox Speculative Loading 行为的实验平台与开发者工具扩展。[体验实验平台 →](https://skylarkning.github.io/Speculation-Rules-Testbench/)

**[TaxiNow](https://github.com/skylarkning/TaxiNow-Release)**  
面向微软模拟飞行 2020/2024 的机场地面导航工具，提供实时飞机定位与详细滑行道信息。

**[SkyCharts](https://github.com/skylarkning/SkyCharts)**  
为运行 iOS 6 的老款 iPad 打造的离线模拟飞行航图应用，支持交互式机场地图。

*TaxiNow 与 SkyCharts 仅用于模拟飞行。*
